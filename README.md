# ODD HAUS: LITTLE SHADOWS

리틀 나이트메어 스타일의 퍼즐·스텔스 어드벤처. **실제 3D 게임**이며, 카메라만 2.5D 사이드뷰로 운용합니다.
`index.html`을 브라우저로 열면 바로 실행됩니다. 그래픽·사운드는 모두 코드로 생성하고, 3D 엔진(Three.js r160)만 CDN(`cdn.jsdelivr.net`)에서 받습니다. 인터넷 연결이 필요합니다.

## 버전 규칙

- `index.html` — 항상 최신 버전
- `versions/ODD_HAUS_LITTLE_SHADOWS_vX.Y.html` — 수정할 때마다 새 버전 파일을 추가하고, 이전 버전은 덮어쓰지 않습니다.

| 버전 | 내용 |
|---|---|
| v1.0 | HTML5 Canvas 2.5D 버티컬 슬라이스: 00 ENTRANCE → 01 LOUNGE → 02 LP LIBRARY(+ 복도 추격) → 03 STUDIO → 엔딩 |
| v1.1 | 웹 게시 대응: 휴대폰 안전 영역·좌우 여백, 세로 화면 안내, 저장소가 막힌 환경에서도 세션 동안 진행 유지 |
| v2.0 | **Three.js 실제 3D 프로토타입** — 3D 아트 바이블의 제작 순서 1–3단계 + 프롤로그. Vin 3D 모델(원판 16 cm · 키 24 cm), 00 ENTRANCE 프롤로그 + 01 LOUNGE 실측 배치, 이동·2.5D 카메라, Mr. ODD 회색 마네킹 손전등 순찰 |

v1.1(2D Canvas 전체 슬라이스)은 `versions/ODD_HAUS_LITTLE_SHADOWS_v1.1.html`에서 그대로 플레이할 수 있습니다.

## v2.0에 들어간 것 (제작 순서 1–3단계 + 프롤로그)

- **1. Vin 3D 프로토타입** — 검은 LP 원판(지름 16 cm, 두께 3.5 cm, 2단 베벨), 앞면 동심원 홈, 뒷면 빨간 라벨, 흰 타원 눈과 깜빡임, 고무호스 팔다리, 흰 4손가락 장갑, 빨간 하이탑, 카세트 플레이어 + LED. 달리면 원판이 레코드처럼 돈다(body_spin). 숙이면 원판이 뒤로 젖혀져 키 15 cm.
- **2. 실측 배치(그레이박스+)** — 가구는 실제 크기: 소파 좌면 45 · 등받이 86 · 밑 틈 18 cm, 커피 테이블 43 cm, 사이드 테이블 70 cm, 문 200 cm. 충돌(COL_) · 은신(HIDE_) 볼륨, 컷어웨이 돌하우스 벽. Mr. ODD는 최종 모델 전까지 180 cm 회색 마네킹.
- **3. 이동 + 카메라** — 걷기 0.82 · 달리기 1.39 · 숙여 걷기 0.45 m/s, 점프 22 cm, 달려 뛰기 수평 80 cm, 낙하 80 cm까지 안전 · 120 cm 초과 사망. 카메라는 FOV 30°, 기본 프레임 1.8 m(현관 1.5 m), Mr. ODD가 가까우면 2.6 m로 물러난다.
- **프롤로그 00 ENTRANCE** — 우편함 틈으로 들어온 Vin, 신발 · 장화 · 신발 벤치로 이동/점프/숙이기를 배우고, 간유리 너머 Mr. ODD의 손전등을 벤치 밑에서 피한 뒤 펫도어로 거실에 들어간다.
- **01 LOUNGE** — 스탠드 램프(그림자) · 창문 달빛(그림자) · 손전등(그림자) 세 광원. Mr. ODD가 램프를 끄고, 소파 앞을 훑고, 커피 테이블 밑을 뒤진 뒤 문을 열어 둔 채 나간다.
- 레코드 조각 3개, 체크포인트 저장/이어하기, 그레이박스 볼륨 뷰(V), 게임패드 · 터치(가상 스틱) 지원.

다음 버전(v2.1)은 제작 순서 4–5단계: 잡기 · 밀기 · 오르기, LP Library.

## 조작법 (v2.0)

| 키 | 동작 |
|---|---|
| A D / ← → | 좌우 이동 |
| W S / ↑ ↓ | 안쪽 · 바깥쪽(깊이) 이동 |
| Shift | 달리기 (발소리가 커짐) |
| Space | 점프 |
| C / Ctrl | 숙이기 · 낮은 틈 통과 · 숨기 |
| Q | Vin의 공명: 숨은 조각과 벽 너머 위협을 표시 |
| F | 뮤직 플레이어 LED (길은 보이지만 적의 시야 거리가 늘어남) |
| V | 그레이박스 볼륨 보기 (충돌 · 은신 · 시야) |
| Esc | 일시정지 |

게임패드와 터치 화면도 지원합니다.
