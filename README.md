# ODD HAUS: LITTLE SHADOWS

리틀 나이트메어 스타일의 2.5D 퍼즐·스텔스 어드벤처. HTML5 Canvas로 만든 **단일 파일** 게임입니다.
`index.html`을 브라우저로 열면 바로 실행됩니다. 외부 에셋이 없고 그래픽·사운드는 모두 코드로 생성합니다(폰트만 Google Fonts, 오프라인이면 기본 글꼴로 대체).

## 버전 규칙

- `index.html` — 항상 최신 버전
- `versions/ODD_HAUS_LITTLE_SHADOWS_vX.Y.html` — 수정할 때마다 새 버전 파일을 추가하고, 이전 버전은 덮어쓰지 않습니다.

| 버전 | 내용 |
|---|---|
| v1.0 | SIDE A 버티컬 슬라이스: 00 ENTRANCE → 01 LOUNGE → 02 LP LIBRARY(+ 복도 추격) → 03 STUDIO → 엔딩 |

## 조작법

| 키 | 동작 |
|---|---|
| ← → / A D | 이동 |
| Shift | 달리기 (발소리가 커짐) |
| Space | 점프 · 가장자리에 닿으면 자동으로 붙잡고 오름 |
| ↓ / S / C | 숙이기 · 틈 통과 · 달리면서 누르면 슬라이딩 |
| ↑ / W | 케이블 오르기 |
| E (길게) | 잡기 · 밀기/당기기 · 손잡이에 매달리기 |
| E | 줍기 · 던지기 |
| Q | Vin의 공명: 숨겨진 물건과 위협의 위치를 감지 |
| F | 손전등 (길은 보이지만 적의 눈에도 띈다) |
| Tab / Esc | 레코드 조각 컬렉션 / 일시정지 |

게임패드와 터치 화면도 지원합니다.
