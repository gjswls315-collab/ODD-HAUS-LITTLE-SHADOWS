# ODD HAUS v2.7 — 스테이지 03–06 설계 · 구현 메모

v2.7은 03 STUDIO의 동선을 다시 짜고, 04 DJ BOOTH · 05 TERRACE · 06 LOCKED ROOM을 **실제로 플레이할 수 있는 3D 그레이박스**로 만들었다.
모든 수치는 게임 좌표(1 unit = 1 m, x = 진행 방향, z = 안쪽이 −, 바닥 y = 0)다. 최종 GLB는 이 위치 · 높이에 맞춰 만든다.

진행: Lounge → LP Library → Studio → **DJ Booth → Terrace → Locked Room → 엔딩**. 출구에 닿으면 화면이 꺼지고 다음 스테이지를 불러온다.

## 공통 시스템

## Buddy (동행 NPC) — 상태

`IDLE`(가까이 · 오래 서 있으면 앉는다) · `FOLLOW`(뒤에서 0.5 m) · `RUN`(1.8 m 넘게 떨어지면) · `SNIFF`(코를 바닥에 — 페달 · 콘센트 · 숨은 점검구를 찾는다) · `GUIDE`(다음 지점까지 앞장) · `ALERT`(스피커 경고 · Bully의 손 · Mr. ODD 발소리: 귀를 젖히고 위협 쪽을 본다) · `BARK`(짖는 순간) · `WAIT`(따라갈 수 없는 곳 — 데스크 · 빔 · 잠긴 문 — 앞에서 앉아 기다린다).
스테이지마다 다닐 수 있는 구간이 있고, 길이 끊기면(테라스 구멍) 잠깐 사라졌다가 다른 쪽 입구에서 나타난다. 가구를 뚫지 않게 가구 앞 바닥 띠(z ≈ 0.5)를 걷는다.
