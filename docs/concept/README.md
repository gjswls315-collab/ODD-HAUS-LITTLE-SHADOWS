# 콘셉트 시트 (기준 그림)

사용자가 준 시트다. 리뷰 후보 모델(`assets/review/`)은 이 그림에 맞춘다. 리뷰 페이지([review/index.html](../../review/index.html))의 **콘셉트 시트** 버튼으로 모델 옆에 띄워 비교한다.

시트에서 읽은 핵심 (리뷰 후보에 반영한 것):
- **Vin** — 검은 레코드 몸에 **빨간 라벨**, 그 위에 세로로 긴 흰 유광 눈 두 개가 거의 붙어 있다(눈꺼풀 없음 · 검은 동공은 안쪽), 뒷면은 홈만 있는 검은 판. 흰 4손가락 장갑, 검은 고무 팔다리, 빨간 하이탑.
- **Buddy** — 캐러멜 · 황갈색 털에 등은 회갈색, 귀 · 눈가는 진한 갈색, 주둥이 · 발은 크림. 부스스한 털, 등 위로 말린 깃털 꼬리, 남색에 금색 사선 넥타이, 새긴 놋쇠 BUDDY 이름표.
- **Bully** — 헝클어진 금발(눈을 덮는 앞머리), 바랜 빨간 캡을 뒤로, 무심한 반쯤 감긴 회색 눈, 빛바랜 검정 티(해골 · 빨간 물감), 헐렁한 차콜 카고 바지(주머니 · 해진 무릎), 갈색 가죽 손목 커프, 빨간 하이탑, **앞에 든 빨간 스트랫 기타**(흰 픽가드) + 갈색 가죽 스트랩.
- **Lounge** — 어두운 벽 · 액자, 짙은 와인 벨벳 소파 · 담요, 남색 · 빨강 페르시아 러그, 무거운 붉은 벨벳 커튼 + 레이스, 주름 잡힌 호박색 램프 갓 · 놋쇠, 짙은 월넛 마루(은은한 반사), 검은 고무 전선, 바닥에 쌓인 LP.
